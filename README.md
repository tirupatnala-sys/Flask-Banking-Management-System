# Bank Management System

A simple Bank Management System developed using Python, Flask, HTML, CSS, and MySQL.

## Features

- Admin Login
- Create Customer
- Edit Customer
- Delete Customer
- Money Transfer
- Customer Dashboard

## Technologies Used

- Python
- Flask
- HTML
- CSS
- MySQL

## How to Run

1. Install Python.
2. Install the required packages:
   ```
   pip install -r requirements.txt
   ```
3. Configure the MySQL database.
4. Run:
   ```
   python app.py
   ```
5. Open:
   ```
   http://127.0.0.1:5000
   ```
